Link a patch panel in one rack to a patch panel in another with [b]one trunk cable[/b] instead of 36. Real data centres do exactly this, with MPO trunks and pre-terminated copper trunks.

[h2]What you get[/h2]
[list]
[*][b]Trunk Patch Panels[/b], copper and fibre (in the shop, below the patch panels). 2U, [b]36 ports[/b] on the front, and a closed box at the back with [b]one trunk port[/b].
[*][b]Two trunk cables[/b] (in the shop, below the cables):
[list]
[*][b]Pre-terminated Cat6 Trunk[/b] for copper panels: a strapped bundle of cables.
[*][b]MPO Trunk Fibre[/b] for fibre panels: one thick aqua cable.
[/list]
[*][b]Cable holders inside every rack[/b], down both side walls, so you can route a trunk up and out of the rack neatly.
[/list]

[h2]How to use it[/h2]
[olist]
[*]Rack a Trunk Patch Panel in each of two racks: copper with copper, or fibre with fibre.
[*]Hold the matching trunk cable, click the trunk port on the back of one panel, route the cable over the holders and ceiling trays, and click the trunk port on the other panel. The game says [b]"Trunk linked: 36 ports"[/b].
[*]Port 1 on one panel now reaches port 1 on the other, and so on up to port 36. Cable your servers and switches into the ports as usual.
[/olist]
Take the trunk cable out and the panels unlink ([i]"Trunk unlinked"[/i]). Put it back and they link again.

[h2]Rules[/h2]
[list]
[*]Trunk ports only take the matching trunk cable, and trunk cables only plug into trunk ports. They hang on any cable holder.
[*]Trunk panels never slow a link down: each link runs at the speed of the cables plugged in at either end.
[*]A trunk panel can't be taken out of its rack while its trunk cable is attached.
[/list]

[h2]Prices[/h2]
[list]
[*]Trunk Patch Panels cost twice the matching vanilla panel: copper $500, fibre $900 and 1,000 XP.
[*]A trunk cable replaces 36 cables, so it costs 36 spools: Pre-terminated Cat6 Trunk $18,000 (36 copper spools), MPO Trunk Fibre $108,000 (36 QSFP fibre spools) and 1,600 XP.
[/list]

[h2]⚠ This is a code mod: pick an install method below[/h2]
Data Center doesn't install code mods by itself. With [b]WorkshopModSync[/b] (a free helper by Bloody) it's subscribe and play. Without it, there's one file to copy.

[h2]Before you install (once, for any code mod)[/h2]
If you already use other code mods, you likely have these. Otherwise:
[olist]
[*][b]MelonLoader 0.7.3[/b] from [url=https://github.com/LavaGang/MelonLoader/releases]the MelonLoader releases page[/url]. Run the installer, point it at Data Center.exe, choose 0.7.3, install. Start the game once, then quit.
[*][b]A fix-up plugin[/b], or no code mods load at all: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3797166996]DS-InteropFix[/url] or [url=https://github.com/mleem97/Il2CppAssemblyFixer]Il2CppAssemblyFixer[/url]. Follow its own instructions.
[/olist]

[h2]How to install: pick one[/h2]
All four ways start from your [b]game folder[/b]. To open it: in your Steam Library, right-click [b]Data Center[/b] → [b]Manage[/b] → [b]Browse local files[/b]. It's the folder with [b]Data Center.exe[/b] in it.

[h3]Way 1: you already have WorkshopModSync (easiest)[/h3]
Check: if the [b]Plugins[/b] folder in your game folder contains [b]WorkshopModSync.dll[/b], you have it.
[olist]
[*]Subscribe to this mod.
[*]Start the game. Done. WorkshopModSync installs your subscribed mods every time the game starts, updates included.
[/olist]

[h3]Way 2: set up WorkshopModSync once, then subscribe and play[/h3]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830456292]WorkshopModSync[/url] is a free helper made by [b]Bloody[/b]. Set it up once, and this mod and other Workshop code mods install and update themselves. It can't install itself, so:
[olist]
[*]Close the game, then subscribe to [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830456292]WorkshopModSync[/url] and to this mod.
[*]Set up WorkshopModSync by following [b]Set it up once[/b] on [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830456292]its page[/url]. It comes with a one-click installer ([b]WorkshopModSyncInstaller.exe[/b]) that finds Data Center and puts it in the right place.
[*]Start the game. Done. This mod installs itself and stays up to date.
[/olist]

[h3]Way 3: copy one file by hand (no helper)[/h3]
[olist]
[*]Subscribe to this mod.
[*]Start the game, wait for the main menu, then quit.
[*]In your game folder, open [b]Data Center_Data[/b] → [b]StreamingAssets[/b] → [b]Mods[/b]. Type [b]NextGenPatchPanels.dll[/b] into File Explorer's search box (top right), and copy the file it finds.
[*]Go back to your game folder, open its [b]Mods[/b] folder, and paste.
[*]Start the game.
[/olist]

[h3]Way 4: without the Steam Workshop[/h3]
Download [b]NextGenPatchPanels.dll[/b] from the [url=https://github.com/checkersx/data-center-next-gen-patch-panels/releases]GitHub releases page[/url] and put it in the [b]Mods[/b] folder in your game folder.

[b]Check it worked:[/b] the MelonLoader console shows [b]Next-Gen Patch Panels v1.0.1[/b], and the shop has Trunk Patch Panels and trunk cables.

[h2]Settings[/h2]
In [b]UserData\MelonPreferences.cfg[/b] in your game folder (it appears after the first run with the mod), under [b][NextGenPatchPanels][/b]. Edit it with the game closed.
[list]
[*][b]PortSpeed = 10000[/b]: trunk panels never slow a link down. Lower it to make them a bottleneck (2 = 10 Gbps).
[*][b]RackMountPoints = true[/b]: the cable holders inside every rack. Set to [b]false[/b] to leave racks as they are.
[*][b]HideRackSlotsWhileCabling = true[/b]: while you hold a cable, rack slots don't get in the way of picking holders and trunk ports inside a rack.
[/list]

[h2]Saves[/h2]
[list]
[*]Saves stay vanilla. Trunk panels are saved as normal patch panels, and a small [i].nextgenpatchpanels.json[/i] file next to the save remembers which ones are trunk panels. A link is just the trunk cable, saved like any other cable.
[*]Remove the mod and your saves still load: trunk panels become normal patch panels, trunk cables are dropped, and trunk cable spools left lying around disappear. Back up your save first.
[*][b]1.0.1 fixes[/b] trunks linking the wrong panels, or none, after loading. Affected saves repair themselves.
[/list]

[h2]Can't pick a trunk port or holder?[/h2]
Hold the cable, aim at it and press [b]F8[/b]. The MelonLoader log lists everything your aim passes through. Please open an issue on [url=https://github.com/checkersx/data-center-next-gen-patch-panels/issues]GitHub[/url] with [b]Data Center\MelonLoader\Latest.log[/b].

[h2]Updating and uninstalling[/h2]
[list]
[*][b]Update with WorkshopModSync:[/b] nothing to do. The update installs the next time you start the game.
[*][b]Update without it:[/b] Steam downloads updates automatically. Copy the new NextGenPatchPanels.dll across again (Way 3, steps 2–4).
[*][b]Uninstall:[/b] with the game closed, unsubscribe first (so WorkshopModSync doesn't put it back), then delete NextGenPatchPanels.dll from the game's Mods folder.
[/list]
